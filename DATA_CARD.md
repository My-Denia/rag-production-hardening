# Data Card — rag-bench synthetic corpus

## Summary

| Field | Value |
| --- | --- |
| Name | rag-bench synthetic company handbook corpus |
| Version | 0.2.1 (paired with package release) |
| Type | Synthetic text only — fictional policies and products |
| Language | English |
| License | MIT (same as repository) |
| PII | None intentional; no real persons, emails, phones, or accounts |
| Intended use | Offline retrieval evaluation, ablations, holdout selection demos |

## Motivation

Provide a small, fully offline, recomputeable RAG evaluation fixture so retrieval/generation/abstain behavior can be scored with an external (non-LLM) judge without paid APIs or proprietary documents.

## Composition

### Corpus (`data/corpus/`)

Ten short plain-text documents about a fictional company (HR, IT, legal, product, facilities, finance, sales, on-call). Documents are crafted to create:

- Lexical and semantic retrieval difficulty
- Cross-document distractors (e.g. Nova vs Helix product lines)
- Unanswerable / out-of-scope questions

### Labels

| Split | Path | Role |
| --- | --- | --- |
| Dev | `data/dev/labels.jsonl` | Arm evaluation and shortlist only |
| Holdout | `data/holdout/labels.jsonl` | Confirm-only after shortlist (sealed without unlock) |
| Regression-v1 | `data/regression_v1/labels.jsonl` | Immutable 35-label dual gate (recall + attribution) |
| Full new set | `data/labels_new.jsonl` | Stratified ≥100 labels regenerated by pipeline |
| Legacy | `data/labels.jsonl`, `data/labels_v1.jsonl` | Historical snapshots |

Each label typically includes: `qid`, `question`, `answerable`, `category`, `gold_spans` (doc + char offsets), `must_contain` (extractive must-haves).

### Categories

Taxonomy IDs are frozen in `config/categories.yaml` (11 categories, min 8 labels each in the stratified set), including unanswerable.

## Collection process

Hand-authored synthetic text. No web scrape, no licensed third-party document dump, no user logs.

## Preprocessing

Chunking strategies are evaluation arms (`fixed_256`, `fixed_512`, `recursive_400_80`), not permanent rewrites of source docs. Source corpus files stay intact.

## Labels / annotation

- Gold spans point into corpus char offsets.
- No LLM-as-judge for scoring.
- Holdout sealed: read requires `RAG_HOLDOUT_UNLOCK=1`; production unlock path is `finalize_selection` only.
- **Gold labels are frozen after scores for regression-v1.** Public release does not edit gold to chase metrics.

## Ethical / sensitive content

None intended. Fictional workplace policies only. Not for training claims about real organizations.

## Limitations

- Tiny domain; metrics do not transfer to production multi-tenant RAG.
- Refusal / abstain arms may score poorly (documented honestly in results).
- MiniLM semantic path needs local model download (`sentence-transformers`); hash/BM25 work offline without it.
- Not a production deployment, security product, or compliance certification.

## Maintenance

- Owners: repository maintainers of the public GitHub project.
- Regeneration: `python -m rag_bench.run_all` from a clean install.
- Breaking label changes require version bump and CHANGELOG note; do not silently edit regression-v1 gold.
